# 「つながりの連鎖」方式 - 具体的なストーリー

## ストーリー1: 情報が自然に広がる

### Week 1: 小さなスタート
**田中支援員**が最初の登録者として、自分が知っている場所を10件登録します。

```
登録した資源:
1. カフェ「月のしずく」 - 面談に使える静かな場所
2. NPO法人わかばの会 - 作業実習受け入れ
3. 市民図書館別館 - 車椅子対応、静か
4. 公園「緑の丘」 - 人が少ない、落ち着く
5. 美容室ハートフル - 障害理解がある
...
```

この時点では、まだ「自分だけのメモ」のような状態です。

---

### Week 2: 最初の検索
**佐藤相談員**が、引きこもりのAさん（20代男性）の支援で悩んでいます。

```
佐藤相談員の行動:
1. システムで「静か 人が少ない 居場所」で検索
2. 田中支援員が登録した「公園『緑の丘』」を発見
3. 「これいいかも！」と思い、実際にAさんと一緒に行ってみる
```

**結果:**
- Aさんが「ここ落ち着く」と気に入る
- 佐藤相談員がフィードバックを追加:
  ```
  「Aさんと訪問。平日午前は本当に人が少なく、
   ベンチでゆっくり過ごせた。Aさんも『また来たい』
   と言っていた。近くに自販機もあり便利。」
  ```

**情報が「生きた」ものに進化:**
- 田中支援員の「人が少ない」という情報が、佐藤相談員によって検証された
- 「近くに自販機あり」という新しい情報が追加された

---

### Week 3: 見つからない → ニーズ記録
**山田支援員**が、車椅子利用のBさんのために理容室を探しています。

```
山田支援員の行動:
1. 「車椅子 理容室 バリアフリー」で検索
2. 見つからない...
3. でも諦めず、ニーズを記録:
   「車椅子で入れる理容室（男性向け、髭剃り対応）
    希望エリア: 八幡東区」
```

**システムに記録されたニーズ:**
```
Need #1: 車椅子対応の理容室
- エリア: 八幡東区
- 対象: 車椅子利用の成人男性
- 要件: 髭剃り対応
- 記録者: 山田支援員
- 状態: open（未マッチ）
```

この時点では何も起きません。でも...

---

### Week 4: 偶然の発見 → 情報追加
**鈴木相談員**が、別件でシステムを見ていて、山田支援員の記録したニーズを発見。

```
鈴木相談員:
「あ！それなら『理容室サンシャイン』があるよ！
 うちの利用者のCさんがいつも使ってる。
 店主さんが車椅子対応に慣れてて、丁寧に
 対応してくれるって聞いてる。」
```

**行動:**
1. 「理容室サンシャイン」を新規登録
2. 山田支援員のニーズに「マッチした」としてリンク
3. 山田支援員に通知が届く

**山田支援員:**
「助かった！早速Bさんに提案してみます」

**これが「つながりの連鎖」:**
- 山田支援員の「見つからない」が可視化された
- 鈴木相談員が偶然それを見て、情報を提供
- 二人の知識が合わさって、問題解決

---

### Week 6: つながりの発見
**佐藤相談員**が、Aさんの次のステップを考えています。

```
佐藤相談員:
「公園『緑の丘』でAさんが落ち着けることはわかった。
 でも、次は何か軽い活動にもチャレンジしてほしい。
 この公園の近くに何かないかな？」
```

**行動:**
1. 「公園『緑の丘』」の詳細ページを見る
2. 地図で近くの資源を検索
3. 「NPO法人わかばの会」が徒歩10分にあることを発見
4. 「つながり」を追加:
   ```
   公園「緑の丘」 --[徒歩10分、段階的支援に使える]--> NPO法人わかばの会
   ```

**この「つながり」が後で役立つ:**
- 別の支援員が「段階的に社会参加を進められる場所」を探す
- この「つながり」情報が検索結果に表示される
- 「まず公園で慣れて、その後NPOで軽作業」という支援パターンが共有される

---

### Week 8: 家族からの情報
**田中支援員**が、Dさんのお母さんと面談中。

```
お母さん:
「実はうちの子、『パン工房ひまわり』っていう
 小さなパン屋さんに時々行くんです。
 店主さんがすごく優しくて、息子がパンを
 選ぶのに時間がかかっても、笑顔で待ってて
 くれるんですよ。」

田中支援員:
「それ、とてもいい情報ですね！
 他の方にも役立つかもしれません。
 システムに登録させてもらってもいいですか？」
```

**登録:**
```
資源: パン工房ひまわり
タイプ: 場所・施設
タグ: #理解がある #ゆっくりOK #地域の居場所
説明: 店主が障害のある方に理解があり、
      ゆっくり選んでも大丈夫な雰囲気。
情報源: Dさんのご家族
```

**家族の知恵も資源に:**
- 支援者だけでなく、家族が知っている「使える場所」も蓄積
- 当事者・家族の視点が加わる

---

### Week 12: システムが育ってきた
3ヶ月後、システムには以下が蓄積されています:

```
資源: 87件
フィードバック: 65件
ニーズ記録: 15件（うち解決済み: 8件）
つながり情報: 42件
ユーザー: 12人（支援員10人、地域住民2人）
```

**新しいパターンが見えてくる:**

1. **「静かな場所」クラスター**
   - 図書館、カフェ、公園がつながって見える
   - 「感覚過敏のある方向けルート」として使える

2. **「作業体験」ルート**
   - NPO → カフェ → パン工房 という段階的な流れ
   - 「徐々に人との関わりを増やす」支援パターンが可視化

3. **「よく検索されるニーズ」**
   - 「手話対応の医療機関」「発達障害児のスポーツ」
   - → 地域で不足している資源が明確に

## なぜ「つながりの連鎖」が機能するのか？

### 1. 完璧を求めない
- 最初は10件でもOK
- 「完全な情報」でなく「使える情報」を重視
- 小さく始めて、使いながら育てる

### 2. 日常業務の延長線上
- 新しいタスクを増やさない
- 「検索して、使って、ちょっとメモする」だけ
- 負担が少ないから続く

### 3. 自然な相互作用
- 「探す人」と「知ってる人」が自然にマッチング
- ニーズの可視化が情報提供を促す
- 使うほど便利になるループ

### 4. 多様な情報源
- 支援者、本人、家族、地域住民
- それぞれが違う視点で情報を持ち寄る
- 多面的な情報が集まる

### 5. 価値の実感
- 「検索したら見つかった！」という成功体験
- 「自分の情報が誰かの役に立った」という充実感
- 使う動機が内発的に生まれる

---

## 実装のポイント

### 最初の3ヶ月が勝負
```
Week 1-2: コアユーザー5-10人で初期データ作成
Week 3-4: 「見つかった！」という成功体験を作る
Week 5-8: フィードバック機能を活性化
Week 9-12: つながり情報とニーズマッチングの活用
```

### 続けるための工夫
- **週1回のミニレポート**: 「今週追加された資源3件」をメール配信
- **月1回の事例共有**: 「このシステムで解決できた事例」を共有
- **感謝の可視化**: 「あなたの情報が○人の役に立ちました」通知

### 広げるための工夫
- **成功事例を語る**: 実際に役立った具体例を共有
- **少しずつ仲間を増やす**: 月に1-2人のペース
- **地域住民への開放**: 準備が整ったら段階的に

---

## まとめ: 「完璧な地図」より「生きた地図」

このシステムは、最初から完璧な「地域資源データベース」を
目指すのではなく、**使いながら育っていく「生きた地図」**を
作ることを目指しています。

- 小さく始める
- 使って育てる
- つながりが生まれる
- 自然に広がる

これが「つながりの連鎖」方式です。

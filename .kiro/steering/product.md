# Product Overview

コミュニティ・リソース・グラフは、障害者・精神障害者の支援に携わる支援者、本人、家族が地域資源を共有・検索できるグラフデータベースシステムです。「完璧な地図」ではなく「生きた地図」として、使いながら情報が自然に成長していく仕組みを目指します。

## Core Capabilities

### 1. 資源の登録・検索
- 支援者が知っている地域資源（場所、活動、人、情報）を登録
- タグベースの柔軟な検索とフィルタリング
- エリア、タイプ、特性による多角的な絞り込み

### 2. つながりの可視化
- 資源間の関係性（近接性、類似性、連続性）をグラフ構造で表現
- 段階的支援ルートの発見（例: 公園 → NPO → 作業場）
- エゴネットワーク分析による資源クラスターの把握

### 3. 情報の育成
- 実際に使った経験のフィードバック蓄積
- 見つからないニーズの記録と可視化
- コミュニティによる情報補完と更新

### 4. ニーズマッチング
- 記録されたニーズと候補資源の推薦
- 「探している人」と「知っている人」の自然な出会い
- 地域で不足している資源の明確化

## Target Use Cases

### Primary: 支援者の情報検索・共有
- 相談支援専門員が利用者のニーズに合った場所・活動を探す
- 実際に使った経験を共有し、他の支援者の判断材料を提供
- 段階的支援プランのための資源連鎖の発見

### Secondary: 本人・家族の参加
- 本人・家族が実際に使っている場所の情報提供
- 当事者視点の評価・コメントの追加
- 「こんな場所を探している」というニーズの表明

### Tertiary: 地域住民の協力
- 地域で障害理解のある場所・人の情報提供
- コミュニティ全体での資源情報の育成

## Value Proposition

### 「つながりの連鎖」方式
- **完璧を求めない**: 最初は10件でもOK、使いながら育てる
- **日常業務の延長**: 新しいタスクではなく、検索・記録の自然な流れ
- **自然な相互作用**: ニーズの可視化が情報提供を促す好循環
- **多様な情報源**: 支援者、本人、家族、地域住民の異なる視点

### データの成長設計
- **Week 1-4**: 初期データ50-100件（コアユーザー5-10人）
- **Week 4-12**: フィードバック蓄積とつながり情報の形成
- **Week 12-24**: 地域の「生きた資源マップ」完成

### 従来アプローチとの違い
- 行政の公式データベース → 実際の使用感が不明、更新が遅い
- 個人のメモ → 共有されず、属人的
- 本システム → 使うほど便利になる、コミュニティの知恵が蓄積
